# STUDY FLOW

## 프로젝트 소개

STUDY FLOW는 대학생의 과목, 과제와 시험 일정, 학습 시간 및 학습 통계를 한곳에서 관리하기 위한 웹 애플리케이션입니다.

## 주요 기능 (PRD 기준)

아래는 전체 개발 범위입니다. 현재 구현된 기능은 대시보드 UI, 과목 CRUD·색상 지정·과목 수 연동, 과제·시험 CRUD·과목 연결·완료 상태·날짜 정렬·D-Day·대시보드 일정 연동입니다. 학습 기록, 실제 학습 통계와 과목별 학습 기록 조회는 개발 예정입니다.

- 대시보드: 오늘의 학습 시간, 과목 수, 진행 중인 과제, 임박한 일정, 최근 학습 기록 및 주간 학습량
- 과목 관리: 과목 등록·조회·수정·삭제, 과목 색상 지정, 과목별 학습 기록 확인
- 과제 및 시험 관리: 일정 등록, 과목 연결, 완료 상태 관리, 마감일 정렬 및 D-Day 표시
- 학습 기록: 스톱워치와 직접 입력을 통한 기록, 과목·날짜·메모 관리, 기록 조회·수정·삭제
- 학습 통계: 일간·주간·월간·누적 학습 시간 및 과목별 학습 시간 비교

## 기술 스택

- HTML
- CSS
- Vanilla JavaScript
- LocalStorage

별도 백엔드 서버 없이 브라우저에서 실행하며, 핵심 기능은 오프라인에서도 사용할 수 있도록 구성합니다.

## 실행 방법

1. 저장소의 최상위 경로에서 `index.html`을 브라우저로 엽니다.
2. 앱은 브라우저의 LocalStorage를 사용해 데이터를 저장합니다.

현재 대시보드 UI와 과목 등록·조회·수정·삭제·색상 지정 기능을 사용할 수 있습니다. Subjects 메뉴의 Add Subject에서 과목을 등록하면 목록과 대시보드 과목 수에 즉시 반영됩니다. 각 과목의 Edit에서 이름·색상을 변경하고 Delete 확인창에서 삭제할 수 있습니다. Tasks & Exams의 Add Task / Add Exam에서 제목·날짜를 필수로, 설명·과목을 선택 입력하여 일정을 등록할 수 있습니다. 각 일정의 Edit에서 유형·제목·설명·날짜·과목을 수정하고 Delete 확인창에서 삭제할 수 있습니다. Mark Complete / Mark Incomplete로 완료 상태를 전환하고 날짜순 목록에서 D-Day를 확인할 수 있습니다. 대시보드에는 미완료 과제 수와 오늘 이후 미완료 과제·시험 중 가까운 일정 3개가 표시됩니다. 학습 기록 기능은 개발 예정입니다.

과목 데이터는 `study-flow.subjects.v1` 키에 `{ version: 1, subjects: [...] }` 형식으로 저장됩니다. 각 과목은 `id`, `name`, `color`(HEX), `createdAt`(ISO 날짜)를 포함합니다. 기존 데이터가 손상됐거나 저장에 실패하면 오류를 표시하며 기존 값을 임의로 초기화하지 않습니다. 수정은 ID를 기준으로 이름·색상만 바꾸고 ID·생성 날짜를 유지하며, 삭제는 확인한 ID의 과목만 제거합니다. 저장 성공 후 목록과 과목 수를 갱신합니다. 데이터는 브라우저와 실행 위치에 따라 분리되므로 같은 브라우저와 실행 위치를 유지하세요.

일정은 `study-flow.tasks.v1` 키에 `{ version: 1, tasks: [...] }` 형태로 저장됩니다. 항목은 `id`, `type`(`task` 또는 `exam`), `title`, `description`, `date`(`YYYY-MM-DD`), `subjectId`(미지정은 `null`), `completed`, `createdAt`을 포함합니다. 수정 시 일정 ID·생성 날짜를 유지하고, 삭제는 확인한 일정 ID만 제거합니다. 저장 실패 시 기존 데이터·목록을 유지합니다. 과목을 삭제해도 일정과 기존 `subjectId`는 유지하며 화면에 ‘미지정 과목’으로 표시합니다. 기존 데이터에 `completed`가 없으면 미완료로 처리하며 조회만으로 원본을 덮어쓰지 않습니다. D-Day는 로컬 날짜 기준으로 계산하고 저장하지 않습니다. 날짜 정렬은 화면에만 적용하며 동일 날짜의 등록 순서를 유지합니다. 대시보드의 Pending Tasks는 시험을 제외한 미완료 과제 수이며, Upcoming Deadlines는 오늘 마감을 포함하고 지난 일정·완료 일정을 제외합니다. 동일 날짜의 등록 순서를 유지하며 계산 결과는 별도로 저장하지 않습니다. 학습 시간·최근 학습 기록·주간 그래프는 아직 실제 데이터와 연결되지 않은 UI입니다.
