# STUDY FLOW

대학생의 과목·과제·시험·학습 시간을 한곳에서 관리하고, 저장한 학습 기록으로 학습량을 확인하는 웹 애플리케이션입니다.

**[배포 사이트 열기](https://sehun717065-sys.github.io/study-flow/)** · [GitHub 저장소](https://github.com/sehun717065-sys/study-flow)

## 주요 기능

현재 작업 트리 기준입니다. 과목별 기록 필터는 아직 커밋·푸시·배포하지 않았으며, 공개 사이트의 확인된 배포 버전은 `d2220fa`입니다.

| 화면 | 구현 기능 |
| --- | --- |
| Dashboard | 로컬 오늘의 TODAY·전체 누적 TOTAL, 전체 과목 수, 미완료 과제 수, 임박한 일정, 최근 학습 기록, 현재 주 선 그래프 |
| Subjects | 과목 등록·조회·수정·삭제, 과목별 색상 지정 |
| Tasks & Exams | 과제·시험 CRUD, 과목 연결 또는 미지정, 완료 전환, 날짜 오름차순 정렬, 로컬 날짜 기준 D-Day |
| Study Records | 스톱워치 시작·일시정지·재개·종료·저장/폐기, 직접 입력, 메모, Manual·Stopwatch 기록 CRUD, 전체/과목별/미지정 기록 필터 |
| Study Records 통계 | 누적·일간·주간·월간 시간, 전체 기간 과목별 시간/비율, 선택 주의 7일 막대그래프 |

대시보드 임박 일정은 오늘을 포함한 미완료 과제·시험 중 가까운 3개입니다. Pending Tasks는 시험을 제외한 미완료 과제 수입니다. 최근 기록은 학습 날짜 내림차순, 같은 날짜는 생성 시각 내림차순으로 최대 3개 표시합니다.

## 기술과 실행 방법

- HTML, CSS 변수와 반응형 레이아웃, Vanilla JavaScript, LocalStorage
- SVG 선 그래프와 HTML/CSS 막대그래프 사용, 외부 라이브러리·CDN·백엔드 없음
- 공개 사이트는 위 링크로 접속합니다. 로컬에서는 저장소 루트의 `index.html`을 브라우저로 엽니다. 별도 설치·앱 빌드는 필요하지 않습니다.
- GitHub Pages 설정은 **Deploy from a branch → main → /(root)** 입니다. 확인한 배포 커밋은 `d2220fa`입니다.

### 기본 사용 흐름

1. Subjects에서 과목을 추가하고 이름·색상을 지정합니다.
2. Tasks & Exams에서 과제·시험을 등록하고 완료 여부를 관리합니다.
3. Study Records에서 과목을 선택해 시간을 측정하거나 Add Manual Record로 날짜·시간·분·초·메모를 입력합니다.
4. 측정을 종료한 뒤 Save Record로 저장하거나 확인 후 Discard로 폐기합니다. 저장된 두 출처의 기록은 모두 수정·삭제할 수 있습니다.
5. Study history 상단 과목 필터로 전체·특정 과목·미지정 기록을 조회합니다. 필터는 목록에만 적용하며 통계는 전체 기록을 기준으로 유지합니다.
6. Dashboard와 Study Records에서 저장된 기록의 통계를 확인합니다.

## 데이터 저장과 계산

| LocalStorage 키 | version 1 저장 구조 | 주요 필드 |
| --- | --- | --- |
| `study-flow.subjects.v1` | `{ version: 1, subjects: [...] }` | `id`, `name`, `color`, `createdAt` |
| `study-flow.tasks.v1` | `{ version: 1, tasks: [...] }` | `id`, `type`, `title`, `description`, `date`, `subjectId`, `completed`, `createdAt` |
| `study-flow.records.v1` | `{ version: 1, records: [...] }` | `id`, `subjectId`, `date`, `durationSeconds`, `note`, `source`, `createdAt` |

- 기록 출처는 `manual` 또는 `stopwatch`이며, 시간은 양의 정수 초로 저장합니다. 직접 입력은 과목·유효한 날짜·양의 시간을 요구하고 미래 날짜와 잘못된 시간 값을 거부합니다. 분·초는 0–59, 메모는 선택이며 최대 2000자입니다.
- Stopwatch는 `performance.now()`와 누적 경과 시간을 사용하고 종료 시 소수점 이하 초를 버립니다. 스톱워치 기록의 날짜는 종료 시점의 로컬 날짜입니다. 같은 페이지의 화면 이동은 측정 상태를 유지합니다.
- 수정은 고유 ID를 기준으로 하며 기록의 ID·생성 시각·출처를 유지합니다. 과목 삭제 후에도 일정·기록은 보존하고 ‘미지정 과목’으로 표시합니다.
- 저장 성공 후 화면을 갱신합니다. 저장 실패 시 기존 데이터와 입력/측정 결과를 유지하고, 손상 데이터는 임의로 덮어쓰지 않습니다. 조회 실패는 정상적인 빈 상태와 구분합니다.
- 통계는 `analytics.js`의 순수 함수로 저장된 초를 합산하며, 원본을 변경하거나 통계 전용 저장 키를 만들지 않습니다. 실행 중·저장 대기 중인 시간은 포함하지 않습니다.
- 일간·주간·월간 집계는 기록의 `date` 기준이며 주는 월요일~일요일입니다. 날짜를 엄격하게 검증하고 달력 날짜 번호로 계산합니다. 과목별 비교는 선택 날짜와 무관한 전체 기간 기준입니다.
- 24시간을 넘는 합계도 유지합니다. 일반 통계는 시간·분 중심으로 표시하고 1분 미만은 초를 안내합니다. 그래프 상세와 기록은 HH:MM:SS 및 정확한 초 정보를 제공합니다.
- 대시보드는 최초 로드·재진입·탭 복귀 때 갱신합니다. 대시보드 주간 그래프는 Study Records의 날짜 선택과 독립적으로 로컬 오늘이 속한 주를 표시합니다.

| 검증 환경 | 확인 범위 | 결과 |

| 격리된 Safari 1440px·375px iframe | 16단계 사용 흐름, CRUD·타이머·통계, 저장 실패/재시도·손상 데이터, 반응형·일부 실제 키보드 경로 | 1,364건 통과, 최종 실패 0건 |

통합 검사에서는 Python 정수·달력 계산과 실제 화면의 초 값을 독립 대조했습니다. 기존 사용자 데이터는 보존했고, 공개 사이트에서는 기존 앱 키가 없는 자동화 환경에서 만든 데이터만 정리했습니다. 통합 검사에서 수집한 JavaScript·미처리 Promise·console.error는 0건이며, 공개 URL의 오류 수집 결과는 페이지 로드 후 주입한 수집기의 관측 구간에 한정합니다.

### 과목별 기록 필터

후속 Safari 1440px·375px iframe의 필터 검사 **84건**, 기존 기능 회귀 **1,336건**을 새로 실행해 모두 통과했습니다. 네이티브 방향키 선택 변경은 미검증으로 제외했으며, 필터 변경은 DOM change 이벤트로 검증했습니다. JavaScript 오류 수집은 0건, 조회 중 쓰기는 0건이며 원본 데이터는 보존했습니다.

Study history의 기본값은 All Subjects입니다. 등록 과목을 선택하면 해당 subjectId의 Manual·Stopwatch 기록을 기존 날짜/생성 시각 최신순으로 표시합니다. 현재 과목 목록에 없는 연결 기록이 있을 때만 ‘미지정 과목’ 옵션을 제공하며 여러 삭제 과목의 기록을 함께 조회합니다. 원본 subjectId는 변경하지 않습니다.

유효한 선택은 화면 재진입·기록 CRUD·과목 이름 변경 후 유지합니다. 선택 과목 삭제 또는 마지막 미지정 기록 삭제로 옵션이 없어지면 All Subjects로 돌아갑니다. 등록 과목의 마지막 기록만 삭제한 경우에는 그 과목 선택을 유지하고 과목별 빈 상태를 표시합니다. 새로고침은 All Subjects로 초기화하며 필터를 저장하지 않습니다. 조회 실패·손상 데이터는 빈 목록과 구분하고 필터를 비활성화합니다. 필터는 기록 목록에만 적용해 모든 통계·그래프·대시보드 값은 전체 기록 기준을 유지합니다.

## 알려진 제한 사항

- 모바일 실기기·가상 키보드·네이티브 선택창·스크린 리더·전체 버튼 Tab 순회·전체 원시 콘솔 로그는 미검증입니다. Safari WebDriver의 `/log` 미지원으로 전체 콘솔을 확인하지 못했습니다. **5단계 전체 완료는 보류 상태**입니다.
- 공개 사이트에서 저장소 장애·날짜 경계 등을 포함한 전체 통합 검사를 다시 실행한 것은 아닙니다. 운영체제 시간대 변경·실제 자정 경과·페이지 이탈 경고 표시도 미검증입니다.
- **미저장 스톱워치 시간과 종료 결과는 새로고침·탭 닫기 후 복원되지 않습니다.** 이탈 경고의 실제 표시는 브라우저 정책에 따릅니다.
- LocalStorage는 브라우저·출처별 저장소입니다. 로컬 파일의 데이터는 배포 사이트로 자동 이전되지 않으며 서버 동기화·계정·백업/가져오기 기능은 없습니다. 브라우저 저장소를 삭제하면 기록도 없어집니다.
- 화면을 계속 보고 있는 동안 자정에 대시보드를 자동 갱신하는 타이머는 없습니다. 배포 사이트의 오프라인 재접속을 위한 전용 캐시도 구현하지 않았습니다.
- 별도 Analytics·Settings 메뉴는 비활성이고, 구현된 통계는 Study Records에서 확인합니다. 과목 필터의 Safari 네이티브 방향키 선택 변경은 자동화에서 확인하지 못했으며 실제 키보드 검증이 남아 있습니다.
- 포커스 없는 DOM click으로 직접 입력 모달을 열면 Escape 후 본문으로 돌아오는 현상을 관찰했습니다. 실제 키보드로 열었을 때의 포커스 복원은 통과했습니다.

## 기술적 배움과 개선점

코드·검증 기록에서 확인할 수 있는 정리이며 개인적인 감정을 대신 작성한 내용은 아닙니다.

- 경과 시간과 화면 갱신을 분리하면 타이머 콜백 지연에도 측정값을 실제 시간으로 계산할 수 있습니다.
- 저장·순수 계산·화면 표시를 분리하면 대시보드와 기록 화면에서 같은 통계를 재사용하고 독립 기준값으로 검증하기 쉽습니다.
- ID 기준 수정/삭제, 초 단위 데이터 보존, 삭제된 과목 연결 보존, 저장 성공 후 화면 갱신이 데이터 일관성의 핵심입니다.
- 잘못된 데이터와 빈 데이터를 구분해야 오류를 정상적인 0시간으로 오해하지 않습니다.
- 회귀 스크립트의 행 위치 가정은 날짜 정렬 이후 잘못된 항목을 선택했습니다. 테스트도 ID를 사용하도록 조정한 사실을 TODO에 기록했습니다.
- 이후 개선 후보는 미검증 환경 확인, 반복 가능한 테스트 자산 정리, 과목 필터의 네이티브 키보드 검증, 모달 포커스 보완입니다. 이번에는 구현하지 않았습니다.
