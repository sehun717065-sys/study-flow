# STUDY FLOW

## 프로젝트 소개

STUDY FLOW는 대학생의 과목, 과제와 시험 일정, 학습 시간 및 학습 통계를 한곳에서 관리하기 위한 웹 애플리케이션입니다.

## 주요 기능 (PRD 기준)

아래는 전체 개발 범위입니다. 현재 구현된 기능은 대시보드 UI, 과목 CRUD·색상 지정·과목 수 연동, 과제·시험 CRUD·과목 연결·완료 상태·날짜 정렬·D-Day·대시보드 일정 연동, 스톱워치 시작·일시정지·재개·종료 및 기록 저장·조회·직접 입력·메모 작성·수정·삭제 및 Study Records 누적·일간·주간·월간 학습 시간 및 과목별 전체 기간 비교입니다. Study Records의 주간 학습량 그래프도 구현했습니다. 대시보드 TODAY·TOTAL 학습 시간도 연결했습니다. 대시보드 최근 학습 기록도 연결했습니다. 대시보드 주간 선 그래프도 실제 기록과 연결했습니다. 과목별 학습 기록 조회는 개발 예정입니다.

- 대시보드: 오늘의 학습 시간, 과목 수, 진행 중인 과제, 임박한 일정, 최근 학습 기록 및 주간 학습량
- 과목 관리: 과목 등록·조회·수정·삭제, 과목 색상 지정, 과목별 학습 기록 확인
- 과제 및 시험 관리: 일정 등록, 과목 연결, 완료 상태 관리, 마감일 정렬 및 D-Day 표시
- 학습 기록: 스톱워치와 직접 입력을 통한 기록, 과목·날짜·메모 관리, 기록 조회·수정·삭제
- 학습 통계: 일간·주간·월간·누적 학습 시간 및 과목별 학습 시간 비교

## 기술 스택

- HTML
- CSS
- Vanilla JavaScript
- LocalStorage

별도 백엔드 서버 없이 브라우저에서 실행하며, 핵심 기능은 오프라인에서도 사용할 수 있도록 구성합니다.

## 실행 방법

1. 저장소의 최상위 경로에서 `index.html`을 브라우저로 엽니다.
2. 앱은 브라우저의 LocalStorage를 사용해 데이터를 저장합니다.

현재 대시보드 UI와 과목 등록·조회·수정·삭제·색상 지정 기능을 사용할 수 있습니다. Subjects 메뉴의 Add Subject에서 과목을 등록하면 목록과 대시보드 과목 수에 즉시 반영됩니다. 각 과목의 Edit에서 이름·색상을 변경하고 Delete 확인창에서 삭제할 수 있습니다. Tasks & Exams의 Add Task / Add Exam에서 제목·날짜를 필수로, 설명·과목을 선택 입력하여 일정을 등록할 수 있습니다. 각 일정의 Edit에서 유형·제목·설명·날짜·과목을 수정하고 Delete 확인창에서 삭제할 수 있습니다. Mark Complete / Mark Incomplete로 완료 상태를 전환하고 날짜순 목록에서 D-Day를 확인할 수 있습니다. 대시보드에는 미완료 과제 수와 오늘 이후 미완료 과제·시험 중 가까운 일정 3개가 표시됩니다. Study Records에서 과목을 선택하고 Start / Pause / Resume으로 시간을 측정할 수 있습니다. 실행 또는 일시정지 중 Stop으로 종료한 뒤 Save Record로 저장하거나 Discard의 확인창에서 폐기할 수 있습니다. Add Manual Record에서는 과목·날짜·시간·분·초·선택 메모를 입력해 기록을 추가할 수 있습니다. 각 저장 기록의 Edit에서 내용을 수정하고 Delete 확인창에서 해당 기록을 삭제할 수 있습니다.

과목 데이터는 `study-flow.subjects.v1` 키에 `{ version: 1, subjects: [...] }` 형식으로 저장됩니다. 각 과목은 `id`, `name`, `color`(HEX), `createdAt`(ISO 날짜)를 포함합니다. 기존 데이터가 손상됐거나 저장에 실패하면 오류를 표시하며 기존 값을 임의로 초기화하지 않습니다. 수정은 ID를 기준으로 이름·색상만 바꾸고 ID·생성 날짜를 유지하며, 삭제는 확인한 ID의 과목만 제거합니다. 저장 성공 후 목록과 과목 수를 갱신합니다. 데이터는 브라우저와 실행 위치에 따라 분리되므로 같은 브라우저와 실행 위치를 유지하세요.

일정은 `study-flow.tasks.v1` 키에 `{ version: 1, tasks: [...] }` 형태로 저장됩니다. 항목은 `id`, `type`(`task` 또는 `exam`), `title`, `description`, `date`(`YYYY-MM-DD`), `subjectId`(미지정은 `null`), `completed`, `createdAt`을 포함합니다. 수정 시 일정 ID·생성 날짜를 유지하고, 삭제는 확인한 일정 ID만 제거합니다. 저장 실패 시 기존 데이터·목록을 유지합니다. 과목을 삭제해도 일정과 기존 `subjectId`는 유지하며 화면에 ‘미지정 과목’으로 표시합니다. 기존 데이터에 `completed`가 없으면 미완료로 처리하며 조회만으로 원본을 덮어쓰지 않습니다. D-Day는 로컬 날짜 기준으로 계산하고 저장하지 않습니다. 날짜 정렬은 화면에만 적용하며 동일 날짜의 등록 순서를 유지합니다. 대시보드의 Pending Tasks는 시험을 제외한 미완료 과제 수이며, Upcoming Deadlines는 오늘 마감을 포함하고 지난 일정·완료 일정을 제외합니다. 동일 날짜의 등록 순서를 유지하며 계산 결과는 별도로 저장하지 않습니다. 대시보드 TODAY는 로컬 오늘의 저장 기록, TOTAL은 전체 저장 기록을 합산합니다. 최근 학습 기록과 주간 선 그래프는 실제 저장 기록을 표시합니다.

스톱워치는 `performance.now()` 기준의 경과 시간과 누적 시간을 사용하며 HH:MM:SS로 표시합니다. 시작 후 저장·폐기 전까지 과목 선택은 잠깁니다. 같은 페이지의 다른 메뉴로 이동해도 측정 및 저장 대기 상태를 유지합니다. 종료 시 마지막 실행 구간을 포함하고 일시정지 구간을 제외하며, 소수점 이하 초를 버립니다. 0초 기록은 저장할 수 없습니다. 저장 실패 시 측정 결과가 유지되어 재시도할 수 있으며, 저장 성공 또는 폐기 확정 후 초기화됩니다.

학습 기록은 `study-flow.records.v1` 키에 `{ version: 1, records: [...] }` 형태로 저장됩니다. 각 항목은 `id`, `subjectId`, `date`(종료 시점의 로컬 `YYYY-MM-DD`), `durationSeconds`(양의 정수), `note`(스톱워치는 빈 문자열, 직접 입력은 메모), `source`(`stopwatch` 또는 `manual`), `createdAt`(ISO 날짜)을 포함합니다. 기존 기록에 추가하며 손상된 데이터는 덮어쓰지 않습니다. 종료 시 생성한 ID를 재시도에도 유지하고 동일 ID 중복 저장을 막습니다. 목록은 날짜 최신순, 같은 날짜는 생성 시각 최신순입니다. 과목이 삭제되어도 기록은 보존되며 ‘미지정 과목’으로 표시합니다.

**저장 전 측정 시간과 종료 결과는 새로고침·탭 닫기 후 복원되지 않습니다.** 미저장 세션이 있으면 페이지 이탈 경고를 요청하며 실제 표시 여부는 브라우저 정책에 따릅니다. 저장된 기록은 새로고침 후에도 유지됩니다. 대시보드 주간 그래프에는 저장된 기록만 반영됩니다.

직접 입력은 과목과 유효한 날짜를 필수로 받고 미래 날짜를 거부합니다. 시간·분·초는 음수·소수·문자 없이 입력하며 분·초는 0–59, 총 시간은 0보다 커야 합니다. 저장 시간은 `시간 × 3600 + 분 × 60 + 초`의 안전한 정수 초입니다. 메모는 선택이며 최대 2000자입니다. 저장 실패 시 모달 입력을 유지하며 재시도할 수 있습니다. 저장 성공 시 모달을 닫고 같은 기록 목록을 갱신하며 Manual / Stopwatch 출처와 메모를 표시합니다. 모달을 사용하거나 저장해도 기존 스톱워치 상태는 유지됩니다.

Stopwatch와 Manual 기록 모두 같은 모달로 수정합니다. 기존 시간을 시간·분·초로 나누어 표시하므로 초 단위 측정값을 잃지 않으며, ID·생성 시각·출처와 변경하지 않은 값은 유지합니다. 삭제된 과목은 안내와 함께 기존 연결을 유지하거나 다른 과목으로 바꿀 수 있습니다. 새 기록에는 현재 존재하는 과목만 연결할 수 있습니다. 수정·삭제는 저장 성공 후 목록에 반영하며 실패하면 기존 기록과 입력을 유지합니다. 삭제는 확인한 ID만 제거합니다. 기록을 수정·삭제해도 실행·일시정지·저장 대기 중인 스톱워치는 유지됩니다.

Study Records의 Total Study Time은 저장된 Manual·Stopwatch 기록의 `durationSeconds`를 모두 합산합니다. `js/analytics.js`의 순수 계산 함수와 기록 화면의 표시 코드를 분리했으며 원본 기록과 저장 구조는 변경하지 않습니다. 24시간 이상도 누적 시간으로 표시하고 1분 미만은 초를 함께 표시합니다. 내부 합계는 초 단위로 유지하고 일반 표시의 분 미만 값은 버립니다. 기록 추가·수정·삭제 및 화면 재진입·새로고침 때 다시 계산합니다. 실행 중이거나 종료 후 저장 대기 중인 시간은 포함하지 않습니다. 통계 결과는 별도로 저장하지 않습니다. 기록 읽기 실패·손상 데이터·정확히 표현할 수 없는 합계는 정상적인 0 대신 오류로 안내하며 기존 데이터를 보존합니다.

Statistics date의 기본값은 로컬 오늘 날짜입니다. 선택 날짜와 같은 `date`의 기록은 Daily, 해당 주 월요일부터 일요일까지는 Weekly, 해당 연·월 1일부터 마지막 날까지는 Monthly로 합산하고 각 범위를 표시합니다. `createdAt`은 집계 날짜 판단에 사용하지 않습니다. 선택 날짜 변경 및 기록 저장·수정·삭제·화면 재진입 시 갱신되며 새로고침하면 날짜 선택은 오늘로 돌아갑니다. 날짜는 YYYY-MM-DD 형식과 윤년·월별 일수를 엄격히 검사합니다. analytics.js는 연·월·일과 그레고리력 날짜 번호를 사용하므로 날짜 집계에 UTC 변환이나 DST 시간 오프셋을 적용하지 않습니다. 잘못된 기준 날짜는 기간 통계에 오류로 표시하며 유효한 누적 합계는 유지합니다. 기존 LocalStorage 구조는 그대로이며 통계와 선택 날짜를 별도로 저장하지 않습니다.

Subject Breakdown은 선택 날짜와 무관한 **전체 기간의 저장된 기록**을 과목별로 비교합니다. analytics.js의 순수 함수가 subjectId로 초를 합산하고 전체 초 합계 대비 비율을 계산합니다. 기록이 없는 등록 과목도 0시간·0.0%로 표시합니다. 존재하지 않는 과목 ID의 기록은 하나의 ‘미지정 과목’으로 묶어 중립 색상으로 표시하며 원본 연결은 유지합니다. 과목별 합계는 전체 누적 합계와 일치합니다. 학습 시간 내림차순, 동률이면 과목 등록 순서로 정렬하고 비율은 소수점 첫째 자리까지 표시합니다. 표시 비율은 반올림으로 합계가 100%와 다를 수 있습니다. 가로 막대와 시간·초·비율 텍스트를 함께 제공합니다. 기록 변경 및 과목 이름·색상 변경·삭제 후 화면 재진입 시 갱신하며 미저장 측정 시간은 제외합니다. 손상된 기록·과목 또는 안전한 정수 범위를 벗어나는 합계는 오류로 표시합니다. 계산 결과는 저장하지 않습니다.

Weekly Study Activity는 Statistics date가 속한 월요일~일요일의 저장 기록을 7개의 세로 막대로 표시합니다. 요일별 날짜·초 합계를 반환하는 순수 함수는 기존 주간 시작일·엄격한 날짜 검증·달력 날짜 번호 계산을 재사용합니다. 7일 합계는 Weekly Study Time과 일치하며 Manual·Stopwatch를 모두 포함합니다. 막대 높이는 주간 최댓값 대비 원본 초 비율이며, 전부 0이면 높이도 0입니다. 양수인 매우 짧은 기록은 최소 2px로 표시해 존재를 알 수 있게 합니다. 요일 아래에 날짜를 표시하고 마우스 올리기·키보드 포커스·클릭/터치 선택 시 전체 날짜와 HH:MM:SS 및 정확한 초를 아래에 표시합니다. 스크린 리더용 이름도 제공합니다. 기준 날짜 변경·기록 저장/수정/삭제·새로고침·화면 재진입 시 갱신하며 미저장 측정은 제외합니다. 오류 시 정상적인 빈 그래프와 구분해 안내하고 원본과 저장 구조는 변경하지 않습니다. 대시보드에는 로컬 오늘이 속한 주의 선 그래프가 표시됩니다.

대시보드의 기존 TODAY 카드 안에 TOTAL 보조 영역을 표시합니다. 두 값은 검증된 저장 기록을 기존 StudyStats.summarize로 계산하며 미저장 측정 시간은 제외합니다. 대시보드 재진입·새로고침·탭 복귀 시 로컬 오늘을 다시 계산하고 날짜 안내도 갱신합니다. 정상적인 빈 기록은 0시간으로 표시하며 1분 미만은 초를 함께 표시합니다. 조회 실패·손상 데이터·합계 범위 초과는 0으로 표시하지 않고 오류를 안내합니다. 저장 키·구조는 변경하지 않습니다.

대시보드 Recent Study Sessions는 저장된 Manual·Stopwatch 기록을 학습 날짜 내림차순, 같은 날짜는 생성 시각 내림차순으로 최대 3개 표시합니다. Study Records와 정렬·HH:MM:SS 표시 함수를 공유하며 과목명·날짜·시간·출처를 제공합니다. 과목 삭제 후에도 기록은 유지하고 ‘미지정 과목’으로 표시합니다. 과목 조회 실패는 ‘과목 정보 확인 불가’ 및 오류 안내로 구분하며, 기록 조회 실패·손상 데이터는 정상적인 빈 상태로 표시하지 않습니다. 사용자 문자열은 텍스트로 렌더링합니다. 초기 로드·대시보드 재진입·새로고침·탭 복귀 때 갱신하며 조회 과정에서 저장 데이터를 변경하지 않습니다.

대시보드 Weekly Study Chart는 `StudyStorage.getRecords()`와 기존 `StudyStats.weeklyActivity()`로 로컬 오늘이 속한 월요일~일요일의 저장 기록을 합산합니다. Study Records의 날짜 선택과는 독립적입니다. 기존 SVG 선·영역·7개 점을 실제 초 값에 맞춰 그리며 세로축은 주간 최댓값에 맞춰 조정합니다. 빈 주는 0 기준선과 안내를 표시하고 손상 데이터·조회 실패는 별도 오류로 구분합니다. 주간 범위·총 HH:MM:SS 및 7일의 날짜·정확한 시간을 텍스트로 제공하며 요일 버튼은 마우스·키보드·클릭으로 상세 정보를 확인할 수 있습니다. 새로고침·대시보드 진입·탭 복귀 때 갱신하며 미저장 시간은 제외하고 저장 데이터는 변경하지 않습니다.
