### 과목 등록·조회 검증 기록 (2026-11-02)

- Safari WebDriver에서 데스크톱 1440px 및 모바일 375px iframe으로 과목 화면과 등록 폼을 확인했다. 모바일 가로 스크롤은 없었으며 모달이 화면 안에 표시됐다.
- 화면 전환, 빈 목록, 공백 이름 거부, 이름 앞뒤 공백 제거, HTML 문자열의 안전한 표시, 색상 반영, 고유 ID, 생성 날짜, 목록 및 대시보드 수 갱신, 새로고침 후 유지 테스트를 통과했다.
- 저장 실패 시 목록 유지와 오류 안내, 손상 데이터 덮어쓰기 방지를 확인했다.
- 고유한 테스트 저장소 키를 사용하는 임시 검증 페이지로 테스트했다. 각 저장소의 기존 키·값이 동일함을 확인하고 이번 테스트 키만 삭제했다.
- Safari 모달 내부 좌표 클릭의 자동화 한계로 폼 제출은 키보드 Enter, 취소는 Space로 검증했다. 모바일 실기기와 네이티브 색상 선택창 조작은 검증하지 않았다.
- 수집된 JavaScript 오류·미처리 Promise 오류·console.error는 0건이다. Safari의 전체 콘솔 로그 조회는 지원되지 않는다.
- 이 시점의 과목 수정·삭제는 미완료였으며, 아래 2-2단계 검증에서 완료했다. 전체 기능 통합 테스트는 미완료다.
