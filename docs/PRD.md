# STUDY FLOW PRD v1.0

## 1. 제품 개요

STUDY FLOW는 대학생의 학습 활동을 통합적으로 관리하는 웹 애플리케이션이다. 과목, 과제와 시험 일정, 학습 시간 및 학습 통계를 한 플랫폼에서 관리한다.

## 2. 실행 환경과 기술 기준

- HTML, CSS, Vanilla JavaScript를 사용한다.
- 데이터는 브라우저 LocalStorage에 저장한다.
- 별도 백엔드 서버 없이 브라우저에서 실행한다.
- 외부 API와 네트워크 서비스 의존성을 최소화하고, 핵심 기능을 오프라인에서도 사용할 수 있게 한다.
- PC와 모바일 브라우저를 지원한다.
- 불필요한 외부 라이브러리나 프레임워크를 추가하지 않는다.

## 3. 사용자와 범위

대학생이 자신의 과목과 학업 일정, 학습 기록을 관리하고 학습량을 확인하는 것을 목표로 한다.

다음 항목은 범위에서 제외한다: 회원가입 및 로그인, 서버 데이터베이스, 사용자 간 협업, AI 자동 학습 계획, 외부 캘린더 연동.

## 4. 기능 요구사항

### 4.1 대시보드

- 오늘의 학습 시간(TODAY)과 전체 기간 누적 학습 시간(TOTAL)을 구분해 표시한다.
- 전체 과목 수와 진행 중인 과제 수를 표시한다.
- 임박한 과제 및 시험 일정을 표시한다.
- 최근 학습 기록을 표시한다.
- 주간 학습량 그래프를 표시한다.

### 4.2 과목 관리

- 과목을 등록, 조회, 수정, 삭제할 수 있다.
- 과목별 색상을 지정할 수 있다.
- 과목별 학습 기록을 확인할 수 있다.

### 4.3 과제 및 시험 관리

- 과제와 시험을 등록할 수 있다.
- 제목, 설명, 날짜를 입력하고 과목과 연결할 수 있다.
- 완료 상태를 관리할 수 있다.
- 마감일 기준으로 정렬하고 마감일 및 시험 D-Day를 표시한다.

### 4.4 학습 기록 관리

- 스톱워치의 시작, 일시정지, 종료 기능으로 학습 시간을 측정한다.
- 학습 시간을 직접 입력할 수 있다.
- 과목, 학습 날짜, 학습 내용 메모를 기록한다.
- 학습 기록을 조회, 수정, 삭제할 수 있다.

### 4.5 학습 통계

- 일별, 주간, 월간 학습 시간을 계산한다.
- 총 누적 학습 시간을 표시한다.
- 과목별 학습 시간을 비교한다.

## 5. 데이터 및 품질 기준

- 데이터 저장과 불러오기는 가능한 한 `js/storage.js`에서 관리한다.
- 과목, 과제, 시험, 학습 기록은 일관된 구조를 사용하고 각각 고유 식별자를 갖는다.
- 저장 전 입력값을 검증한다.
- 데이터가 없거나 비어 있어도 앱이 정상 동작해야 한다.
- 등록, 수정, 삭제 시 화면과 저장소를 함께 갱신한다.
- 기존 사용자 데이터를 임의로 초기화하거나 삭제하지 않는다.
- 데이터 구조 변경 시 기존 데이터 유지 방법을 검토한다.
- 시맨틱 HTML, 명확한 변수·함수 이름, 일관된 디자인을 사용하고 모바일 터치 환경을 지원한다.
- 데이터가 없는 화면에는 안내 문구를 표시하며, 실제 작동하지 않는 버튼이나 메뉴를 두지 않는다.

## 6. 개발 및 검증 기준

- 개발은 승인된 Todo 순서에 따라 작은 기능 단위로 진행한다.
- 기존 정상 기능을 임의로 삭제하거나 변경하지 않는다.
- 기능 구현 후 브라우저에서 실제 실행하고, 기능·콘솔·LocalStorage·PC 및 모바일 화면을 확인한다.
- 실제 테스트를 하지 않은 작업을 완료했다고 보고하지 않는다.
- 주요 변경 사항은 README에 반영하고 개발 과정의 문제와 최초 Todo 대비 결과 차이를 기록한다.
